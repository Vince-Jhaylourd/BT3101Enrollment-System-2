
#  Student Enrollment Management System

A desktop-based enrollment management application developed using **C# Windows Forms and SQLite**. The system streamlines student records management, enrollment, assessment, section assignment, and payment transactions through a role-based platform.

---

##  About the Project

The **Student Enrollment Management System** is designed to simplify and organize school enrollment operations. It provides a centralized platform where administrators, registrars, and cashiers can manage their respective tasks efficiently.

The system features three user roles, each with specific functionalities and access to designated modules.

##  Technologies Used

- **Programming Language:** C#
- **Framework:** .NET Framework
- **User Interface:** Windows Forms
- **Database:** SQLite
- **Database Library:** Microsoft.Data.Sqlite
- **IDE:** Visual Studio
- **Version Control:** Git and GitHub

##  User Roles and Functionalities

###  Administrator
- Manage student records.
- Manage grade levels and sections.
- Monitor enrollment information.
- View and generate student information reports.
- Access the administrative dashboard.

###  Registrar
- Add, update, search, and maintain student information.
- Process student enrollment.
- Perform student assessments.
- Assign students to grade levels and sections.
- Generate student information reports.
- Filter reports by grade level, section, and academic year.
- Preview and print student reports.

###  Cashier
- View student assessment details.
- Record and process student payments.
- View payment history.
- Monitor outstanding balances.
- Track daily collections.

##  Main System Modules

| Module | Description |
|---|---|
| Login and Authentication | Role-based system access |
| Student Maintenance | Student information management |
| Section Management | Section creation and maintenance |
| Student Assessment | Tuition, fees, discounts, and assessment calculations |
| Payment and Cashiering | Payment recording and transaction monitoring |
| Student Information Report | Filtered reports and printing |
| Dashboard | Enrollment and financial summaries |

##  Database Structure

The system uses **SQLite**, a lightweight database that stores application data locally without requiring a separate database server.

### Database Tables

- `Users` – Stores user accounts and roles.
- `Students` – Stores student personal information.
- `Sections` – Stores grade levels, section names, and capacities.
- `Enrollments` – Stores student enrollment records.
- `Assessments` – Stores student assessment details and fees.
- `Payments` – Stores payment transactions.

- Centralize and organize student information.
